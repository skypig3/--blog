# 测试用例与人工测试步骤

配套 [README 第 10 节](../README.md#10-测试方法)。自动化测试与端到端脚本覆盖接口层，
本文覆盖**界面层**的人工回归步骤（含预期结果与失败判据），按角色分组。

## 0. 环境准备

| 步骤 | 命令 | 预期 |
|---|---|---|
| 启动后端 | `cd backend` → `set JAVA_HOME=D:\Dev\JDK21` → `mvnw.cmd spring-boot:run` | 控制台出现 `Started BlogApplication`，<http://localhost:8080/api/system/info> 返回 `status=UP` |
| 启动前端 | `cd frontend` → `pnpm dev` | <http://127.0.0.1:5173> 可打开 |
| （可选）重置数据 | 停服务，删除 `backend/data/blog.db`（含 `-wal`/`-shm`）后重启 | 自动建表并写入演示账号 |
| （可选）导入演示数据 | `java -jar target/blog-backend-1.0.0.jar --blog.load-demo-data=true` | ⚠ 会清空现有业务数据，用于回归前恢复基线 |

演示账号见 [README 第 9 节](../README.md#9-演示账号)：`admin/Admin@123`、`xiaoming/User@123`、`xiaohong/User@123`。

## 1. 游客（未登录）

| 编号 | 用例 | 操作 | 预期结果 |
|---|---|---|---|
| G-01 | 浏览已发布文章 | 打开 `/` | 首页显示 Hero、最新文章卡片（含标题/摘要/作者/时间/阅读量/封面）、热门文章、分类与标签计数 |
| G-02 | 列表分页与排序 | 打开 `/articles`，切换排序下拉、翻页 | 列表按发布时间刷新，分页条生效 |
| G-03 | 标题关键词搜索 | 顶栏搜索框输入 `Vue` 回车 | 地址变为 `/search?q=Vue`，结果只剩匹配标题的文章 |
| G-04 | 分类筛选 | 点首页侧栏某分类 | 进入 `/categories/:id`，只显示该分类文章 |
| G-05 | 标签筛选 | 点首页某标签 | 进入 `/tags/:id`，只显示该标签文章 |
| G-06 | 空结果提示 | 搜索一个不存在的词（如 `zzzz`） | 显示「没有符合条件的内容」空态，不报错 |
| G-07 | 文章详情 | 打开任一已发布文章 | Markdown 正确渲染（标题/代码块/列表），显示作者、时间、阅读量、点赞与收藏按钮 |
| G-08 | 受限操作需登录 | 在详情页点赞或发表评论 | 提示需要登录并跳转 `/login`，不得直接完成写操作 |

## 2. 注册用户（xiaoming）

| 编号 | 用例 | 操作 | 预期结果 |
|---|---|---|---|
| U-01 | 注册校验 | `/register` 留空或填非法邮箱提交 | 前端逐项提示必填/格式；用户名或邮箱重复时服务端返回明确提示 |
| U-02 | 注册成功 | 填合法用户名/邮箱/密码提交 | 注册成功并登录（或跳登录页），新账号为普通用户 |
| U-03 | 登录（用户名或邮箱） | `/login` 分别用 `xiaoming` 与邮箱登录 | 均成功；点「普通用户」可快捷填充演示账号 |
| U-04 | 登录失败提示 | 输入错误密码 | 明确提示「用户名或密码错误」，不泄露账号是否存在 |
| U-05 | 刷新保持登录态 | 登录后刷新页面 | 顶栏仍为用户菜单，未退化为游客态 |
| U-06 | 退出登录 | 点退出 | 回到游客态；再执行受限操作需重新登录 |
| U-07 | 修改资料 | `/me` 改昵称/头像/简介并保存 | toast「资料已更新」，用户名与邮箱不可改 |
| U-08 | 修改密码 | 验证原密码后设新密码 | 成功后当前会话立即失效，跳回登录页 |
| U-09 | 写文章存草稿 | `/editor` 填标题与正文，存草稿 | toast「草稿已保存」，地址由 `/editor` 变为 `/editor/:id` |
| U-10 | 提交审核 | 「我的文章」对草稿点提交 | 状态变为「待审核」，可撤回 |
| U-11 | 撤回 | 对「待审核」文章点撤回 | 回到「草稿」 |
| U-12 | 查看审核结果 | 打开被驳回文章详情或编辑页 | 作者可见驳回原因；「我的评论」中被驳回的评论显示驳回原因 |
| U-13 | 编辑/删除自己的文章 | 编辑或删除本人文章 | 生效；删除需二次确认 |
| U-14 | 归属校验 | 尝试编辑/删除他人文章（改 URL 里的 id） | 被拒（403/提示无权），不得成功 |
| U-15 | 评论与回复 | 在详情页发表评论、回复他人评论 | 进入「待审核」；审核通过后前台可见，计入评论数 |
| U-16 | 点赞/收藏幂等 | 对同一文章反复点赞、收藏 | 计数在 0/1 间切换，不重复累加；「我的收藏」可见 |
| U-17 | 越权访问后台 | 普通用户直接访问 `/admin` | 路由守卫重定向到 `/403`，标题「没有权限」；后端接口同样 403 |
| U-18 | 禁用账号不可登录 | 账号被管理员禁用后登录 | 拒绝登录；已登录会话访问受保护数据也被拒 |

## 3. 管理员（admin）

| 编号 | 用例 | 操作 | 预期结果 |
|---|---|---|---|
| A-01 | 仪表盘统计 | 打开 `/admin` | 用户/文章/已发布/待审核/评论/待审核评论/阅读量七项数字**实时来自数据库**，与接口一致；显示近期文章与待办审核 |
| A-02 | 文章筛选 | 文章页按关键字、分类、**作者**、状态组合筛选 | 结果随之刷新；筛选下拉包含作者选项 |
| A-03 | 查看待审全文 | 点待审文章「查看」 | 弹窗显示完整正文与作者/分类/状态 |
| A-04 | 审核通过 | 点「通过」→ 确认 | toast 成功，列表刷新，侧栏待审角标 -1；文章前台公开 |
| A-05 | 驳回必填原因 | 点「驳回」，原因留空 | 拒绝提交并提示必须填写原因 |
| A-06 | 重复审核防护 | 对已通过/已撤回的文章再次审核 | 状态机拒绝，提示不可重复审核 |
| A-07 | 下架违规文章 | 对已发布文章点「下架」并填原因 | 状态变「已下架」，前台不再展示；原因作者可见 |
| A-08 | 删除文章 | 删除不应保留的文章 | 删除成功并记录日志 |
| A-09 | 评论审核 | 评论页按**作者**/内容/状态筛选，通过或驳回 | 生效并写日志；驳回必填原因；回复同样被覆盖 |
| A-10 | 查看所属文章 | 评论详情 | 显示所属文章标题 |
| A-11 | 用户管理筛选 | 用户页按用户名/邮箱/昵称搜索，按角色/状态筛选 | 结果刷新 |
| A-12 | 禁用/恢复账号 | 对某用户禁用再恢复 | 状态切换生效并写日志；被禁用者无法登录 |
| A-13 | 修改用户角色 | 对某用户「设为管理员」/「取消管理员」 | 角色更新生效；不能修改自己的角色 |
| A-14 | 最后一个管理员保护 | 尝试禁用/降级唯一的管理员 | 被拒，系统始终保留至少一个启用管理员 |
| A-15 | 用户接口不泄露密码 | 查看用户详情 | 无密码/密码哈希字段 |
| A-16 | 分类与标签维护 | `/admin/taxonomy` 新建/改名/删除 | 生效；分类与标签计数正确 |
| A-17 | 操作日志 | `/admin/logs` 浏览并按动作/目标筛选 | 显示操作者、动作、目标、结果、说明与时间 |
